## 3. หลักเกณฑ์การกำหนดช่วงหน้าเอกสาร (Page Selection Methodology)

เอกสารเล่มหลักสูตร มคอ.2 มีความหนา 300–450 หน้า แต่โครงสร้างข้อมูลใน Ground Truth มีเป้าหมายสกัด 2 ส่วน:
1. **ช่วงหน้ากลุ่มวิชาเฉพาะเลือก (Electives / Flexible Courses)**: เป็นส่วนที่ระบุรายวิชาเลือกทั้งหมดในแต่ละกลุ่ม/แขนง โดยในเฉลยจะกำหนด `year = 0` และ `semester = 0`
2. **ช่วงหน้าตารางแผนการศึกษา (Academic Plan)**: เป็นส่วนตารางหมวด 3.1.4 หรือ 3.3 (แผนสหกิจศึกษา) ซึ่งแจกแจงรายวิชาในแต่ละปีและภาคเรียนตั้งแต่ปี 1 ถึงปี 4 (`year = 1..4`, `semester = 1..2`)

### ตารางการระบุหน้าของแต่ละหลักสูตร:
* **DSBA (`DSBA_curriculum.pdf`)**: 
  - วิชาเลือก: หน้า 19–25 | แผนสหกิจ: หน้า 33–39
  - ระบุ: `--pages 19-25,33-39`
* **BIT (`BIT_curriculum.pdf`)**: 
  - วิชาเลือก: หน้า 24–25 | แผนสหกิจ: หน้า 31–35
  - ระบุ: `--pages 24-25,31-35`
* **IT (`fulldoc_it.pdf`)**: 
  - วิชาเลือก: หน้า 26–30 | แผนสหกิจ: หน้า 39–45
  - ระบุ: `--pages 26-30,39-45`
* **AIT (`fulldoc_AIT.pdf`)**: 
  - วิชาเลือก: หน้า 21–22 | แผนการศึกษา: หน้า 23–26
  - ระบุ: `--pages 21-26`

## 4. นวัตกรรมและการปรับปรุงในระบบ Engine (`lab7b_curriculum.py`)

1. **Universal Multi-Layout Parsing Engine**:
   - **Case 1 (Single-line)**: รองรับ `[รหัส] [ชื่อไทย] [หน่วยกิต]` ในบรรทัดเดียว (DSBA, AIT, IT)
   - **Case 2 (BIT Multi-line Lookback)**: แก้ปัญหาชื่อวิชาภาษาไทยที่พิมพ์อยู่บรรทัดบนก่อนรหัสวิชา โดยมีระบบ Lookback ย้อนหลัง 3 บรรทัดข้ามหัวตารางย่อย `(ทฤษฎี-ปฏิบัติ-ศึกษาด้วยตนเอง)`
   - **Case 3 (Elective Bullet Lists)**: สกัดวิชาเลือกที่มีรหัสขึ้นต้น ตามด้วยชื่อภาษาอังกฤษและหน่วยกิตในบรรทัดถัดไป
   - **Case 4 (Code-first Isolated)**: รองรับกรณีรหัสวิชาอยู่แยกบรรทัดเดี่ยว ๆ ตามด้วยชื่อไทยและอังกฤษ
2. **Thai Font PUA Encoding Normalization**:
   - แก้ปัญหาฟอนต์ไทยใน PDF ที่แปลงสระและวรรณยุกต์เป็น Private Use Area (PUA) เช่น `\uf702`, `\uf70a`, `\uf70e` ทำให้โปรแกรมค้นพบข้อความ `ปีที่ X ภาคการศึกษาที่ Y` ในหลักสูตร IT ได้ครบถ้วนทุกภาคการศึกษา
3. **Category & Code Prefix Intelligence**:
   - เพิ่มการรองรับรหัสวิชาศึกษาทั่วไป `9664xxxx` สำหรับหลักสูตรนานาชาติ (BIT) ควบคู่กับ `9064xxxx`
   - จัดหมวดหมู่วิชาเฉพาะครอบคลุมทุกสาขาของคณะ (`0601`, `0602`, `0603`, `0604`, `0606`)
   - รองรับช่องวิชาเลือกที่เป็นตัวพิมพ์ใหญ่/เล็ก (`96644XXX`, `06036xxx`, `xxxxxxxx`)
4. **Deterministic & High-Speed Pipeline**:
   - เลี่ยงปัญหา Token Overflow หรือ LLM Loop Timeout จากโมเดลขนาดเล็กบน Local
   - ความเร็วเฉลี่ยระดับ **0.8 – 1.1 วินาทีต่อเล่ม** ได้ผลลัพธ์แน่นอน 100% ทุกครั้งที่รัน

## 5. วิธีการรันโปรแกรม (Execution Guide)

### 1. ตรวจสอบความพร้อมของระบบ
```bash
python lab7b_curriculum.py --check
```

### 2. คำสั่งรันสกัดข้อมูลแยกตามหลักสูตร

#### หลักสูตร DSBA:
```bash
python -u lab7b_curriculum.py \
    -i ../data/input/fulldoc_dsba.pdf \
    --pages 19-25,33-39 \
    -g ../data/ground_truth/DSBA/DSBA_academic_plan_coop.json \
    -p text \
    -o output/DSBA \
    --program DSBA
```

#### หลักสูตร BIT:
```bash
python -u lab7b_curriculum.py \
    -i ../data/input/fulldoc_BIT.pdf \
    --pages 24-25,31-35 \
    -g ../data/ground_truth/BIT/BIT_academic_plan_coop.json \
    -p text \
    -o output/BIT \
    --program BIT
```

#### หลักสูตร IT:
```bash
python -u lab7b_curriculum.py \
    -i ../data/input/fulldoc_it.pdf \
    --pages 26-30,39-45 \
    -g ../data/ground_truth/IT/IT_academic_plan_coop.json \
    -p text \
    -o output/IT \
    --program IT
```

#### หลักสูตร AIT:
```bash
python -u lab7b_curriculum.py \
    -i ../data/input/fulldoc_AIT.pdf \
    --pages 21-26 \
    -g ../data/ground_truth/AIT/AIT_academic_plan.json \
    -p text \
    -o output/AIT \
    --program AIT
```

### 3. โหมดประเมินผลอย่างเดียว (--eval-only)
สามารถนำไฟล์ผลลัพธ์ที่เคยสกัดไว้มาประเมินซ้ำกับ Ground Truth ได้ทันที:
```bash
python lab7b_curriculum.py --eval-only output/IT/pred_text.json -g ../data/ground_truth/IT/IT_academic_plan_coop.json
```
